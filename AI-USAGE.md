# Sentinel — AI Usage Disclosure

This document records how AI tools were used during development of the Sentinel project for the NEXORA 2026 challenge.

---

## AI Tools Used

| Tool            | Usage                                                       |
|-----------------|-------------------------------------------------------------|
| AI Assistant    | Project scaffolding, architecture design, code generation   |

## Usage Details

### Phase 1 — Project Foundation

- **Project structure:** AI assisted in generating the Maven project layout, pom.xml dependencies, and package architecture.
- **Configuration:** AI generated application.yml, Docker, CI, and build configuration.
- **Documentation:** AI drafted README.md, DECISIONS.md, LIMITATIONS.md, and this file.
- **Test scaffolding:** AI created the smoke test and ArchUnit architecture test skeleton.
- **Code review:** All generated code was reviewed and validated by the developer.
